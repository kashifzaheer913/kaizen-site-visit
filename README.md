# Kaizen Site Visit App
1. Google Sheet > Extensions > Apps Script > paste apps-script/Code.gs > Deploy as Web app (Anyone).
   (Agar pehle deploy kiya hua hai: Deploy > Manage deployments > Edit > Version: New version > Deploy. URL wohi rahega.)
2. Push this folder to GitHub (main branch). GitHub Actions builds the APK automatically.
3. Download Kaizen-Site-Visit.apk from the Releases page, install, paste Web App URL in Settings.

Features: add / edit / delete, multi-select (long press), filter, Excel & PDF export (filtered ya selected), smart back button.
